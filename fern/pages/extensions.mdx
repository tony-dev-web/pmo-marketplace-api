## Écrire son propre connecteur

Lisez le code d'une extension existante avant de partir de zéro : elles règlent toutes les mêmes questions, et de la même manière.

- Le client Python [`exemples/pmo_client.py`](https://github.com/tony-dev-web/pmo-marketplace-api/blob/main/exemples/pmo_client.py) tient en cent lignes, sans dépendance hors `requests`.
- La collection [Postman](https://www.postman.com/tony-d7b3346b-8131745/piece-moto-occasion/collection/9d8okfr/api-vendeur-piecemotooccasion) permet d'essayer les sept requêtes avant d'écrire une ligne.
- La description [`openapi.yaml`](https://github.com/tony-dev-web/pmo-marketplace-api/blob/main/openapi.yaml) génère un client dans la plupart des langages.
