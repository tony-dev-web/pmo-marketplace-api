---
title: "Webhook des commandes"
description: "Notification signée HMAC-SHA256 envoyée à chaque commande payée sur PieceMotoOccasion."
---

Renseignez une URL de notification dans votre espace vendeur : chaque commande payée y est envoyée en `POST` JSON, signée par l'en-tête `X-Pmo-Signature`.

```
X-Pmo-Signature: sha256=<HMAC-SHA256 du corps avec votre jeton>
```

## Vérifier la signature

Vérifiez avant de lire le contenu, sur le corps **brut** : re-sérialiser le JSON change les octets, donc la signature. Comparez en temps constant.

```python
import hashlib
import hmac

def signature_valide(jeton, corps, entete):
    attendu = "sha256=" + hmac.new(jeton.encode(), corps, hashlib.sha256).hexdigest()
    return hmac.compare_digest(attendu, entete or "")
```

Répondez `200` dès réception et traitez ensuite, sans attendre la fin de votre traitement.
